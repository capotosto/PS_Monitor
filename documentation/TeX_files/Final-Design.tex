\chapter{Final Design}
\label{chap:finaldesign}

Final design consists of a six-channel monitoring
interface, Arduino GIGA controller, local touchscreen,
Ethernet interface, and EPICS control system interface.

\section{Hardware Design}

The system monitors six separate power rail supplies:
+5VA, +5VB, +5V, -5V, +15V, and -15V.

Each of the six channels measures the voltage of
supply and the voltage on a high-precision current sense
resistor using an LTC2945 device. Digital isolation
separates each channel of measurements from the I2C bus
on the controller side.

Custom-made PCBs house the sensor interfaces, isolation
circuits, and Ethernet components. The data acquisition and
processing is done by Arduino GIGA R1 WiFi module, while
GIGA Display Shield provides the local user interface.

\section{Software and Communication}

The firmware regularly acquires measurements, converts
the results to engineering units, applies correct polarity
and performs evaluation against upper and lower alarms for
voltage and current.

Measurements, alarms and communication status are locally
displayed and sent via Ethernet using the PSC protocol.
EPICS IOC provides access to the information for the Phoebus
operator interface.

Network settings and alarms are stored in non-volatile memory.

\section{Implementation Modifications}

Final implementation of the design involved some modifications
to the initial design, namely to isolated I2C interface.
Logic inversion and pull-up modification have been added to
solve the communication issues found during hardware bring-up.

Prototype incorporates all necessary modifications and
hardware and software developed during the project.
